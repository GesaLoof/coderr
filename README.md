# Coderr

A freelance services marketplace connecting businesses offering services with customers who need them. Built with Django and Django REST Framework. The project is hosted and live under www.gesaloof.com.

## Installation


### Local Development

**1. Clone the repository**
```bash
git clone https://github.com/GesaLoof/coderr
cd coderr
```

**2. Create a `.env` file** in the project root (see `.env.example` for reference):

**3. Build and start the containers**
```bash
docker compose up --build
```

This will automatically:
- Start the PostgreSQL database
- Run migrations
- Create a superuser
- Start the development server at `http://localhost:8000`

**4. Seed demo data (optional)**
```bash
docker compose exec web python manage.py seed_demo_data
```

## Tech Stack

- **Django** — REST API and business logic
- **Django REST Framework** — API endpoints and token authentication
- **PostgreSQL** — production database
- **Gunicorn** — production WSGI server
- **Nginx** — reverse proxy and static file serving
- **Docker** — containerization and deployment

## Roles

- **Business** — creates service offers with tiered pricing packages
- **Customer** — browses offers, places orders, leaves reviews

## Features

- Role-based registration (Business / Customer)
- Service offers with multiple pricing tiers (e.g., Basic, Standard, Premium)
- Order placement from offer detail tiers — order data is snapshot at purchase time
- Review and rating system — one review per business, gated by order history
- Full-text search and filtering on offers (by type, price range, delivery time)
- Profile management with avatar upload, location, phone, bio, and working hours

## Data Models

| Model | Description |
|---|---|
| `Profile` | Extends Django User with a role type (`business` / `customer`) |
| `CoderrProfile` | Extended profile: name, avatar, location, phone, bio, working hours |
| `Offer` | Service listing created by a business |
| `OfferDetail` | Pricing tier within an offer (delivery time, price, features, revisions) |
| `Order` | Customer purchase — snapshot of an OfferDetail at order time |
| `Review` | Customer rating and review of a business (one per reviewer-business pair) |

## API Endpoints

All routes are prefixed with `/api/`.

### Auth

| Method | Endpoint | Description |
|---|---|---|
| POST | `/registration/` | Register as Business or Customer; returns auth token |
| POST | `/login/` | Authenticate and receive token |
| POST | `/logout/` | Delete current token (requires auth) |

### Profiles

| Method | Endpoint | Description |
|---|---|---|
| GET / PATCH | `/profile/{id}/` | Retrieve or update a profile |
| GET | `/profiles/business/` | List all business profiles |
| GET | `/profiles/customer/` | List all customer profiles |

### Offers

| Method | Endpoint | Description |
|---|---|---|
| GET | `/offers/` | Paginated list; supports `search`, `offer_type`, `creator_id`, `min_price`, `max_delivery_time`, `ordering` filters |
| GET | `/offers/{id}/` | Single offer detail |
| POST | `/offers/` | Create offer with nested pricing tiers (Business only) |
| PATCH / PUT | `/offers/{id}/` | Update offer (owner only) |
| DELETE | `/offers/{id}/` | Delete offer (owner only) |

### Orders

| Method | Endpoint | Description |
|---|---|---|
| GET | `/orders/` | List all orders (authenticated) |
| GET | `/orders/{id}/` | Single order detail |
| POST | `/orders/` | Place an order from an `offer_detail_id` (Customer only) |
| PATCH | `/orders/{id}/` | Update order status (Business only) |
| DELETE | `/orders/{id}/` | Delete order (Staff only) |
| GET | `/order-count/{id}/` | Total orders for a business |
| GET | `/completed-order-count/{id}/` | Completed orders for a business |

### Reviews

| Method | Endpoint | Description |
|---|---|---|
| GET | `/reviews/` | List all reviews (authenticated) |
| GET | `/reviews/{id}/` | Single review detail |
| POST | `/reviews/` | Create a review (Customer only; requires prior order with that business) |
| PATCH | `/reviews/{id}/` | Update own review |
| DELETE | `/reviews/{id}/` | Delete own review |

### Misc

| Method | Endpoint | Description |
|---|---|---|
| GET | `/base-info/` | Aggregate stats: business count, offer count, review count, average rating |
